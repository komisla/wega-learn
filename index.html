XML — Daten als Baum

XML strukturiert Daten als verschachtelte Elemente:

  <brief>
    <absender>Carl Maria von Weber</absender>
    <datum>1817-03-15</datum>
    <text>Liebe Caroline...</text>
  </brief>

Jedes Element kann Kinder, Text und Attribute haben.
TEI ist ein XML-Format — du wirst genau solche
Strukturen abfragen und transformieren.
🧭

XPath — Navigation im Baum

XPath ist eine Sprache um Elemente im XML-Baum
zu finden:

  //absender          → findet <absender>
  //brief/datum       → findet <datum> in <brief>
  //brief[@id='001']  → findet <brief> mit Attribut

Du beschreibst einen Pfad — XPath geht ihn ab.
🏷️

Namespaces — damit Namen eindeutig bleiben

TEI-Elemente stehen in einem Namespace:
  xmlns:tei="http://www.tei-c.org/ns/1.0"

Ohne Präfix würde XPath "persName" nicht finden
— es sucht nach dem falschen Namespace.

  Richtig:   //tei:persName   ✓
  Falsch:    //persName        ✗ (findet nichts!)

Du wirst das oft brauchen — merke es dir jetzt.
